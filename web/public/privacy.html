Zásady ochrany soukromí

Aktualizováno: 21. listopadu 2026

Tyto zásady platí pro hru Metropole od Oldřicha Vořechovského (ol1n): appku pro iOS a Android (com.ol1n.metropole) a webovou verzi na této adrese. Metropole nesbírá žádné osobní údaje.

Appka (iOS, Android)

  • Nemá účet, reklamy, analytiku, sledování ani hlášení pádů.
  • Nepřipojuje se k internetu: mapa města je součástí instalace.
  • Nic neodesílá vývojáři ani nikomu jinému.
  • Nastavení z ladicího panelu se drží jen v paměti po dobu běhu appky.

Webová verze

  • Stránka i mapová data se stahují z GitHub Pages. GitHub při tom jako každý web server vidí vaši IP adresu; řídí se zásadami GitHubu. Vývojář tato data nedostává.
  • Hra nepoužívá cookies ani analytiku. Výsledek benchmarku (?bench) se jen zobrazí na obrazovce; odešle se, jen když ho sami zkopírujete a pošlete.

Mapová data

Mapy pocházejí z © OpenStreetMap contributors (licence ODbL) a Overture Maps Foundation. Ve hře nejsou žádné údaje o vás ani o vaší poloze.

Děti

Hra od nikoho, tedy ani od dětí, nesbírá osobní údaje.

Změny

Pokud se zásady změní (například s novou funkcí, která potřebuje internet), nová verze bude na této adrese s novým datem dřív, než změna vyjde.

Privacy Policy

Last updated: November 21, 2026

This policy covers Metropole, a game by Oldřich Vořechovský (ol1n): the iOS and Android app (com.ol1n.metropole) and the web version at this address. Metropole collects no personal data.

  • App. No account, ads, analytics, tracking or crash reporting. It makes no internet connection: the city map ships with the install. It sends nothing to the developer or anyone else. Debug-panel settings live in memory only while the app runs.
  • Web version. The page and map data are served by GitHub Pages, which sees your IP address like any web server, under GitHub's privacy statement. The developer does not receive it. No cookies, no analytics. A benchmark result (?bench) is only shown on screen; it leaves your device only if you copy and send it yourself.
  • Map data. © OpenStreetMap contributors (ODbL) and Overture Maps Foundation. The game holds no data about you or your location.
  • Children. The game collects no personal information from anyone, children included.
  • Changes. An updated policy will be posted here with a new date before a change ships.
  • Contact. business@olin.now
